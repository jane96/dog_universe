# 犬之岛 - 全球犬种3D可视化系统

> 一个基于 Three.js 的沉浸式3D交互应用，展示全球犬种的地理分布、3D模型资产及AI智能推荐系统。

## 📋 项目概述

“犬之岛”是一个融合地理可视化、3D建模与人工智能的Web应用。用户可以在3D地球上探索全球犬种的分布，查看高精度3D犬种模型及其动态动画，并通过AI助手获取个性化的宠物推荐。

## 运行
`浏览器访问 http://localhost:8080`

## ✨ 核心功能

| 功能模块 | 描述 |
|---------|------|
| 🌍 3D地球可视化 | 基于Three.js构建的可交互地球，支持旋转、缩放 |
| 🐕 3D犬种模型 | GLTF/GLB格式高精度模型，支持骨骼动画 |
| 🔲 网格资产系统 | 将地球划分为网格区域，犬种按地理位置精准定位 |
| 🏷️ 智能标签 | CSS2DRenderer实现的始终面向相机的文字标签 |
| 🎬 自动巡航 | 电影级相机漫游，依次展示核心犬种 |
| 🤖 AI智能推荐 | 基于用户输入需求，推荐最适合的犬种 |
| 📊 详情面板 | 展示犬种详细信息：寿命、产地、体型、饲养指南等 |
| 🎮 动作控制 | 支持切换犬种动画（坐立、握手、翻滚等） |

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| Three.js (r132.2) | 3D场景渲染、地球模型、相机控制 |
| GLTFLoader + DRACOLoader | 加载压缩的3D模型文件 |
| CSS2DRenderer | 高性能文字标签渲染 |
| Tween.js | 平滑动画过渡（相机、材质透明度） |
| TailwindCSS | UI样式框架 |
| Model-Viewer | 侧边栏中的3D模型预览组件 |

### 🤖 AI推荐逻辑（静态模拟）
```用户在输入框中描述养宠需求（如“独居公寓、上班族、想要独立安静的狗”），系统会：

1.模拟AI分析过程（3.5秒扫描动画）

2.锁定匹配的犬种（演示版本锁定为“柴犬”）

3.相机平滑飞移至该犬种位置

4.弹出3D悬浮推荐气泡，显示推荐原因

5.高亮对应网格并打开详情面板
```
